# Wallet

## Problem
People pay monthly subscriptions they don't use, forget their renewal dates, or buy a new item when they could have repaired the old one under warranty.

## User
Anyone with subscriptions, purchases, or monthly commitments.

## Solution
The user enters their subscriptions, purchases, and warranties, and the app alerts them before a renewal or a warranty expiry.

## Differentiator
AI calculates how much the user can save, and suggests what to cancel and what to repair instead of replacing.

## MVP features (build only these)
- Subscription logging, renewal alerts, saving purchase receipts, warranty expiry alerts, and a potential savings calculator.

## Vision (do not build yet)
It's not just an expense tracker. It combines preventing forgotten subscriptions with using warranties to avoid paying extra.

And honestly, I can't say this idea has never been done before. This kind of service already exists in different forms. The real differentiator will be combining these functions in a simple experience that suits Kuwaiti users.

## Stack
- Frontend: React with Vite
- Backend: Node.js and Express
- Database: MongoDB Atlas with Mongoose
- Payments: Stripe test mode only, if needed

## Rules
- Build one feature fully, then the next.
- Small steps. Explain each change.
- Never put secrets in code. Use Replit Secrets or .env.
- Do not add features that are not in the MVP list.
